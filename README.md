# Collate — local-first PDF AI for Mac

Collate is a native macOS workspace for chatting with, summarizing, organizing, and citing PDFs. In Local AI mode, document processing stays on the Mac. Optional cloud AI uses OpenAI or Anthropic with the credentials selected by the user.

## Product facts

- **Platform:** macOS 13.5 or later
- **Category:** PDF workspace and document AI
- **Primary tasks:** PDF chat, summaries, page citations, highlights, organization, and export
- **AI modes:** Local AI or optional user-selected OpenAI or Anthropic with the user's own API key
- **Access:** Free download; no Collate account required to use the Mac app
- **Source status:** Proprietary application

Image-only scanned PDFs without selectable text cannot currently be summarized or chatted with. AI output can be inaccurate or incomplete, so important claims should be checked against the cited PDF pages.
